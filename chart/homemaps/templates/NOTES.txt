HomeMaps is installed. On a fresh install there is no map and no routing graph
yet; the pods wait for them. Start the two build jobs once by hand:
{{ if .Values.tiles.enabled }}
  kubectl -n {{ .Release.Namespace }} create job --from=cronjob/{{ include "homemaps.component" (dict "root" . "name" "tiles") }}-planetiler planetiler-initial
{{- end }}
{{- if .Values.valhalla.enabled }}
  kubectl -n {{ .Release.Namespace }} create job --from=cronjob/{{ include "homemaps.component" (dict "root" . "name" "valhalla") }}-build valhalla-initial
{{- end }}

After that they refresh themselves on their schedule. Photon fetches its own index.
To check: helm test {{ .Release.Name }} -n {{ .Release.Namespace }}
